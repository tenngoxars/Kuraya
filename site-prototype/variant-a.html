解題

壹

是什么

一部影片，从文件名到一面书架。Kuraya 自动识别番号、取回元数据与封面，按演员与番号归档成册，最后生成一页随时可开的片库。

01

本地优先

元数据、nfo 与海报全部落在本地，与影片文件同存。

02

纯离线片库页

重建出的 index.html 不依赖任何服务，拷走即可浏览。

03

点封面即播

经 kuraya: 协议调起本机播放器，无需中转。

04

无框架测试

自检与测试零框架依赖，一把命令即可验证。

05

三平台二进制

macOS · Windows · Linux 各平台即装即用。

工序

貳

工作流程

三道工序，从散乱到成册。全程可在终端里一瞥而过。

一

识别

从文件名识别番号，联网获取元数据与封面。

二

归档

按演员名与番号归档，生成 nfo 与海报。

三

重建

重建片库 index.html，可搜索、筛选、点封面播放。

片藏

參

片库预览

重建后的片库页面——一页纯离线 HTML，无服务、无追踪，只有你的收藏。

片库 / index.html 搜索番号 · 标题 · 演员…
全部 未观看 按演员 按番号
100 部 · 纯离线 · 可搜索 点击封面即播

点封面即经 kuraya: 协议调起本机播放器 —— 一册离线可读的影片目録。

手引

肆

安装

三平台二进制，一行命令即可。装好后运行 kuraya 即开始整理。

macOS

Apple Silicon

$ brew install tenngoxars/tap/kuraya

Windows

PowerShell

$ irm https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.ps1 | iex

Linux

bash

$ curl -fsSL https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.sh | bash

源码安装

需 Python 3.11+

$ pipx install .

伍
