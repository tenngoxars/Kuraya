影片刮削与编目工具 —— 把散乱的影片文件整理成带封面和元数据的有序收藏，并生成可离线浏览的片库页面。

GitHub 仓库 ↗ v0.1.0 · MIT

01它是什么

KURAYA 是跑在你本机上的命令行工具：识别番号 → 抓取元数据 → 整理归档 → 生成片库页。不建账号、不上传文件，一切发生在本地。

01识别$ kuraya scrape

扫描目录，从文件名提取番号（KUR-001），联网获取元数据与封面。可用 --dry-run 先演练。

KUR-001.jsonposter.jpg
02归档$ kuraya

按 演员名 / 番号 整理目录结构，为每部影片写出 nfo 与海报，方便其他刮削器与播放器识别。

演员名/KUR-001/movie.nfo
03重建$ kuraya rebuild

生成纯离线 index.html：可搜索、可筛选，点封面经 kuraya: 协议直接调起本机播放器。

index.html2.4 MB

03特性 $ kuraya --features

kuraya --features
$ kuraya --features
  local-first    本地优先：元数据、封面与页面全部保存在本机
  offline        纯离线片库：搜索与筛选零网络请求
  play           kuraya: 协议：点封面调起本机播放器
  no-framework  TUI 与测试零框架依赖
  binaries       三平台二进制：macOS / Windows / Linux 一键安装

04安装

$brew install tenngoxars/tap/kuraya

# macOS（Apple Silicon，M 系列芯片）

PS>irm https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.ps1 | iex

# Windows：在 PowerShell 中执行

$curl -fsSL https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.sh | bash

# Linux：需要 curl 与 bash

$pipx install .

# 源码安装：需要 Python 3.11+ 与 pipx

05命令行速览

命令说明
$ kuraya# 完整流程：刮削 → 归档 → 重建
$ kuraya scrape --limit 3# 只处理前 3 个文件（先演练）
$ kuraya rebuild# 仅重建片库页面
$ kuraya selftest# 自检：环境、依赖与网络
$ kuraya config# 查看 / 修改配置
$ kuraya --dry-run# 演练模式：只演示，不落盘
$ kuraya --quiet --yes# 静默 + 自动确认，适合脚本
