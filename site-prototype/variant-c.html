工作流程

三步，从杂乱到有序

识别、归档、重建——每一步都可以单独执行，也可以一条命令走完全程。

01 / 识别番号

刮削元数据

扫描文件名中的番号，联网抓取标题、演员与封面。想先试水？scrape --limit 3 只刮三个。

02 / 归档整理

生成 nfo 与海报

按 演员名 / 番号 归档到影片库目录，自动生成 nfo 元数据与 poster 海报，结构永远整整齐齐。

03 / 重建片库

输出离线页面

一条 rebuild 生成可搜索、可筛选、点击即播的 index.html——纯离线，断网也能逛。

特性

为长期收藏而设计

不做云同步、不做账号、不做订阅。kuraya 只把你硬盘里的影片整理好，然后安静地待命。

◈

本地优先

元数据、海报、片库页全部落在你的硬盘上，不上传任何数据，不依赖任何服务。

◎

纯离线片库

生成的 index.html 无需服务器、无需联网，双击即开，断网也能完整浏览。

▶

点击即播

封面经 kuraya: 协议直接调起本机播放器，选片不用先翻目录找文件。

▤

三平台二进制

macOS、Windows、Linux 各有一行命令安装的预编译版本，开箱即用。

✓

无框架测试

测试套件零框架依赖，跑得快、看得懂，改起来没有心理负担。

↻

一键重建

新增文件后运行 kuraya rebuild，片库页永远是最新状态。

安装

一行命令，三平台就位

预编译二进制，无运行时依赖，装完即用。

macOS

Apple Silicon

$ brew install tenngoxars/tap/kuraya
Windows

PowerShell，一条命令

$ irm https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.ps1 | iex
Linux

bash，一条命令

$ curl -fsSL https://raw.githubusercontent.com/tenngoxars/Kuraya/main/install.sh | bash
源码安装

想改源码或自己打包？pipx install . 需要 Python 3.11+。

$ pipx install .

KURAYA 蔵屋

影片刮削与编目工具。把散乱的影片文件，整理成带封面和元数据的有序收藏——然后生成一座可离线浏览的片库。

关于内容：KURAYA 蔵屋 仅整理你已合法持有的本地文件；不提供、不索引、不分发任何影片内容。
